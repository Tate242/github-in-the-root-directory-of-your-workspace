# Part 1: The Fallen Star — Asset Generation Deck

Complete generation prompts for every scene and character in Part 1. Copy-paste ready.

## How To Use This Deck

1. **Generate the Character Locks (Section 1) FIRST.** Use the best result as an image reference (`--cref` in Midjourney, character reference in Veo/Runway) in every scene prompt that features that character.
2. Every prompt already contains the style anchor and character descriptors — paste the full line, don't mix-and-match.
3. **Video prompts** (Veo/Runway) embed camera motion. **Still prompts** (Midjourney) are for keyframes, the thumbnail, and character locks.
4. Everything is vertical **9:16**. Add title text in post (Canva/Photoshop) — never let the AI render text.

## Consistency Rules

- **Negative prompt (all tools):** `text, watermark, logo, extra fingers, deformed hands, horizontal format, landscape orientation, modern clothing, earth settings`
- Lock the seed on your approved Zilex and Alia generations; reuse those seeds for every scene they appear in.
- Zilex appears in shots S4, S5, S6, S8, S10 + thumbnail — same reference image every time.
- The stone's look never changes: *silver-platinum, glowing veins of light, resting in its crater*.
